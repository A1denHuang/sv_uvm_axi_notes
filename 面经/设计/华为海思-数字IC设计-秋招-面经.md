# 华为海思 · 数字IC设计 · 秋招面经

> 来源：小红书 ｜ 线下集中面试，一天内完成全部轮次。

## 面试流程

- 线下集中面试，一天内完成全部轮次

### 一面

- 自我介绍
- 项目深挖
- AXI 的 outstanding、out-of-order、interleave 特性，以及 unaligned 非对齐传输

### 二面

- 自我介绍、项目
- 手撕代码难题：A/B 模块时钟 10MHz，每周期输出 10bit 数据送入 C 模块；C 模块有 10MHz 和 100MHz 两个时钟域，整合 A、B 传输数据，每个时钟周期输出 1bit；10MHz 与 100MHz 时钟异步，支持反压，要求资源消耗最少，自定义接口写 C 模块代码
- 面试中可协商调整条件；该题对手撕代码能力、PPA 优化要求很高

### 三面（偏综合，几乎无技术题）

- 用三个关键词介绍自己
- 对比其他候选人的优劣势
- 如何理解"以客户为中心，以奋斗者为本"
- 对加班文化的看法
- 招聘定级的理解
- 介绍团队竞赛成功经历与过往失败经历
- 实习选公司的考量；实习时是否主动放弃个人想法，成为 mentor 后是否会建议实习生放弃想法
- 实习中 mentor 提出印象最深的需求
- 新项目启动方案，带实习生做新项目的指导思路
- 国内外知名芯片公司与行业大牛认知
- 是否愿意去国外工作
- 对比华为和其他公司的优劣势
- 反问环节
