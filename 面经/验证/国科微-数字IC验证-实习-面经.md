# 国科微 · 数字IC验证 · 实习面经

> 来源：小红书 ｜ 整体难度较高，面试官重点考察基础功底与抽象验证思维。

## 技术面

### 项目相关

- 项目与知识的学习来源、验证环境搭建方式
- 测试点分解思路（要求阐述分解方法论）；若使用 AI 自动分解测试点，如何判断 AI 输出结果是否正确
- reset test 验证思路：需验证复位后 cs 释放、spi 空闲状态、AXI 输出清零
- 追问：reset 场景下数据传输到一半发生复位中断，scoreboard 是否会报错及背后原因
  - 答案：不会报错——复位后重新传输一帧，校验复位后的数据包

### UVM 八股

- phase 运行顺序、顺序设计原因
- seq、sqr、seq_item 的定义与相互关系
- 静态 phase 和动态 phase 区别

### 协议与组件

- AXI4 协议多通道并行 ID 的实现原理
- driver 如何利用 mailbox 完成 ID 解耦

## 二面（HR 面）

- 了解国科微的渠道
- 为什么选择验证岗位，是否考虑过设计岗
- 谈谈对 IC 验证的理解
- 个人经历
- 实习时间，如何平衡学校课题与实习工作
